## Challenges & Findings

The assignment instructions referenced installing “Claude Code” and “Codex” inside Cursor.

While researching and testing the current versions of Cursor and VS Code, I found that modern AI-development workflows have changed significantly across tutorials, platforms and IDE versions.

I may still be partially incorrect in my understanding, but based on my research and testing:

* Current free Cursor versions differ from many online tutorials
* Codex integration worked successfully through VS Code
* Claude Code currently appears to require paid subscription/API-based access for full setup

Since I did not have access to paid API billing, I focused on finding the next best working solution instead of abandoning the setup process.

Rather than forcing unsupported configurations, I explored alternatives, compared workflows, and documented the process honestly.
